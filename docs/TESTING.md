# Тестирование

## Автотесты (без звука, годятся для CI)

Все тесты — «математический loopback»: сигнал синтезируется, зашумляется (гауссов шум + тишина по краям, имитация микрофона) и декодируется тем же кодом, что работает в эфире.

| Команда | Что проверяет |
|---|---|
| `python tests/test_nego_loopback.py` | все 4 режима (2/4/8/16-FSK, разные пресеты) с авто-согласованием; совместимость со старым форматом; **дрейф часов ±0.25%** (запись растянута — следящий декодер обязан удержать сетку) |
| `python tests/test_file_loopback.py` | файловый тракт: случайный бинарный файл → кадр → сигнал + шум → файл, сверка SHA-256 |
| `python tests/test_loopback.py` | текстовый режим (базовый) |
| `node tests/test_webapp.js` | JS-реализация: SHA-256 и CRC32 против эталонов Node, loopback на 44100 Гц, согласование, дрейф; кадр из JS бит-в-бит совместим с Python |

## Испытания в воздухе

Методика: передача текста и файлов на расстоянии 0.3–0.5 м, обычная комната.

| Сценарий | Режим | Результат |

## Найденные и исправленные проблемы

1. **Ложный маркер на гармонике.** Маркер 3000 Гц ловился на 3-й гармонике тона 1000 Гц (искажения дешёвых динамиков). Исправлено переносом маркера + правило в валидаторе частот.
2. **Слипание битов при 100 мс.** Жёсткая сетка попадала на границы символов → добавлена точная синхронизация по 16 символам (перебор сдвигов ±0.6 символа).
3. **Развал длинных передач (>15 с).** Кварцы устройств расходятся на ~0.1–0.3%, сетка уезжает на соседние символы: начало кадра чистое, хвост — каша. Исправлено следящим декодером (early-late tracking). Диагностический признак: служебная посылка (6 с) проходит, длинные данные — нет.

## Практические рекомендации

- Начинайте с режима по умолчанию (4-FSK, 100 мс, standard) — он проверен лучше всего
- Телефон → телефон: пресет high (телефонные динамики слабы ниже ~1.5 кГц), громкость 70–80% (на 100% — искажения)
- Шумно / далеко: 2-FSK + 200 мс
- Если согласование проходит, а данные нет — режим данных агрессивнее, чем позволяет канал: снижайте скорость или вернитесь к standard

## ТУРБО и FEC

`python3 tests/test_turbo_loopback.py` — параллельные полосы 4×16 и 6×16 @ 50 мс
(320/480 бит/с), дрейф часов +0.2%, восстановление побитого блока XOR-чётностью,
ожидание блоков чётности при обрезанном кадре. Секция «ТУРБО/FEC» есть и в
`node tests/test_webapp.js`.
