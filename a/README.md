# 🔊 Аудиомодем XXI века — 4-FSK

Передача любого файла между устройствами **только через звук** — динамик и микрофон.
Без интернета, Bluetooth, кабелей и QR-кодов. Целостность подтверждается **SHA-256**.

---

## Быстрый старт (2 минуты)

### 1. Установка

**Windows:**
```bat
pip install numpy sounddevice
```

**Linux (Ubuntu/Debian):**
```bash
sudo apt update && sudo apt install -y python3-pip portaudio19-dev
pip3 install numpy sounddevice
```

> ⚠️ На Linux без `portaudio19-dev` установка `sounddevice` падает — ставьте его первым.

### 2. Проверка без звука (всё ли работает)
```bash
python test_loopback.py        # текстовый режим
python test_file_loopback.py   # файловый режим + SHA-256
```
Оба должны напечатать `OK`.

### 3. Передача файла между двумя компьютерами

**На принимающем** (запускать ПЕРВЫМ!):
```bash
python file_receiver.py --duration 60
```

**На передающем** (после старта приёмника):
```bash
python file_sender.py --file путь/к/файлу.txt
```

Передатчик сам подскажет, какой `--duration` нужен приёмнику.
Принятый файл появится в папке `received/` под исходным именем,
а на экране будет вердикт: `✅ SHA-256 совпал — файл восстановлен байт-в-байт`.

### Рекомендуемые условия
- Громкость системы передатчика: **50–70%** (на максимуме звук искажается).
- Расстояние динамик–микрофон: от 20 см до 1–2 м.
- Во время передачи не разговаривать рядом с микрофоном.
- Если устройств несколько — выберите нужный микрофон/динамик: `python devices.py`, затем `--device N`.

## 📱 Телефон (Android / iPhone)

В папке `webapp/` лежит **`audiomodem.html`** — полноценный модем в одном файле,
работает в браузере без интернета и полностью совместим с Python-версией
(можно передавать телефон → ноутбук и ноутбук → телефон).

**Как положить на телефон (до демо, это легально — запрещена только передача СОДЕРЖИМОГО файла не через звук):**
скачайте `audiomodem.html` на телефон любым способом ЗАРАНЕЕ (как установку приложения)
и откройте в Chrome/Safari.

**Использование:**
1. Вкладка **Принять** → «Начать запись» (разрешить микрофон) → запустить передатчик →
   после окончания звука «Стоп и декодировать» → кнопка «Скачать принятый файл».
2. Вкладка **Передать** → ввести текст или выбрать файл → «Передать звуком».

> Если браузер не даёт доступ к микрофону с file:// — на ноутбуке выполните
> `python -m http.server` в папке webapp и откройте страницу с телефона ЗАРАНЕЕ —
> сама передача файла всё равно идёт только через звук.

## Архитектура

### Слои

```
Приложение   file_sender.py / file_receiver.py / audiomodem.html
      │        (файлы, прогресс, отчёт о целостности)
Канальный    protocol.py — кадр AM01: имя, размер, SHA-256,
      │        блоки по 64 байта + CRC32 каждого блока
Физический   sender.py / receiver.py — 4-FSK модем
```

### Физический уровень (4-FSK)

- Символ = 2 бита, длительность **100 мс** → скорость **20 бит/с**.
- Частоты: `00`→1500 Гц, `01`→1900 Гц, `10`→2300 Гц, `11`→2700 Гц.
- Маркер начала/конца: 3500 Гц, 0.5 с (вне гармоник рабочих частот).
- Плавные фронты 5 мс у каждого тона (нет щелчков и расплывания спектра).
- Детектор: корреляция с комплексной экспонентой (аналог алгоритма Гёрцеля);
  анализируется середина символа (защитный интервал 25 мс с каждого края).
- **Точная синхронизация**: после грубого поиска маркера граница данных уточняется
  перебором сдвигов ±60 мс с шагом 5 мс по уверенности классификации первых 16 символов
  и положению границы маркера (решает проблему рассинхрона на полсимвола).
- Диапазон 1500–3500 Гц выбран как оптимальный для встроенных динамиков/микрофонов
  ноутбуков и телефонов → работает на любом железе (универсальность).

### Формат кадра (канальный уровень)

```
╔═ ЗАГОЛОВОК ════════════════════════════════╗
║ "AM01"      4 байта  магическая последовательность ║
║ флаги       1 байт   bit0: текст/файл              ║
║ длина имени  1 байт                                ║
║ размер      4 байта  длина данных (до 4 ГБ)        ║
║ SHA-256    32 байта  хеш всего файла               ║
║ имя файла   N байт   UTF-8                          ║
║ CRC32       4 байта  контроль заголовка            ║
╠═ ДАННЫЕ (блоками) ══════════════════════════╣
║ блок ≤ 64 байта + CRC32 (4 байта)  × N блоков    ║
╚═══════════════════════════════════════════════║
```

Два уровня контроля: CRC32 локализует, КАКОЙ участок повреждён;
SHA-256 даёт криптографическое доказательство байт-в-байт восстановления.

## Сценарий демонстрации экспертам

1. Показать исходный файл и его хеш: `certutil -hashfile файл SHA256` (Windows) / `sha256sum файл` (Linux).
2. На приёмнике: `python file_receiver.py --duration 60` (показать, что сети/кабелей нет, можно включить авиарежим).
3. На передатчике: `python file_sender.py --file demo.txt`.
4. После приёма показать вердикт `✅ SHA-256 совпал` и сверить хеши вручную (п. 1).
5. Бонус: принять тот же сигнал телефоном через `audiomodem.html` — кросс-платформенность.

Совет: для демо берите файл до ~200–300 байт (при 20 бит/с это 1.5–2.5 минуты звука).
Накладные расходы кадра: 46 байт + имя файла + 4 байта на каждые 64 байта данных (~6%).

## Ограничения

- Скорость 20 бит/с (≈ 2.5 байт/с) — сознательный выбор в пользу надёжности на любом железе.
- Односторонний канал: нет подтверждений/перезапроса — при ошибке передача повторяется целиком
  (но CRC32 блоков точно показывает, что именно побилось).
- Громкий шум в полосе 1.5–3.5 кГц (речь вплотную к микрофону) может испортить символы.
- На телефоне браузер может включать шумоподавление — мы его отключаем явно, но поведение зависит от модели.

## Идеи для развития (бонусные баллы, не реализовано сознательно — не меняем рабочий принцип перед дедлайном)

- Обратный канал подтверждений (ACK) и перезапрос только битых блоков (номера уже известны из CRC32).
- 8-FSK: +50% скорости без изменения длительности символа.
- Коды коррекции ошибок (Хэмминг/Рид–Соломон) — исправление одиночных сбоев без повтора.
- Адаптация скорости под качество канала.

## Частые проблемы

| Симптом | Решение |
|---|---|
| `Маркер не найден` | Запускайте приёмник ДО передатчика; поднимите громкость |
| `Передача оборвалась раньше конца` | Увеличьте `--duration` (передатчик печатает нужное значение) |
| SHA-256 не совпал, битые блоки | Ближе устройства, громкость 50–70%, тише в комнате, повторить |
| `sounddevice` не ставится на Linux | `sudo apt install portaudio19-dev`, затем `pip3 install sounddevice` |
| Не тот микрофон/динамик | `python devices.py` и флаг `--device N` |
